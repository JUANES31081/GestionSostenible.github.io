# GestionSostenible.github.io

Aplicación web didáctica para la actividad **Mundial de la Sostenibilidad**, basada en el artículo:

**Bond, A., Morrison-Saunders, A., & Pope, J. (2012). _Sustainability assessment: the state of the art_.**

## Contenido del proyecto

- `index.html`: estructura principal de la aplicación.
- `styles.css`: estilos visuales y personalizaciones.
- `app.js`: lógica de interfaz, interacción y flujo de actividad.
- `data.js`: datos base (países, tarjetas y criterios).
- `Artículo 6 Sustainability assessment.pdf`: artículo de referencia.
- `Mundial_Sostenibilidad_Tarjetas_y_Tablero.docx`: documento de apoyo de la actividad.

## Cómo ejecutar en local

Opción rápida con Python:

```bash
python -m http.server 5500
```

Luego abre en el navegador:

`http://127.0.0.1:5500/`

## Publicación en GitHub Pages

Este repositorio está pensado para publicarse desde la rama `main`.

Pasos generales:

1. Ir a **Settings** del repositorio en GitHub.
2. Abrir la sección **Pages**.
3. En **Source**, seleccionar **Deploy from a branch**.
4. Elegir la rama **main** y carpeta **/(root)**.
5. Guardar y esperar la URL pública.

## Notas

- Proyecto desarrollado para fines académicos (Universidad EAN).
- La actividad utiliza una metáfora táctica (fútbol) como recurso didáctico para analizar criterios de evaluación de sostenibilidad.
